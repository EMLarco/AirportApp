# Seguridad

- Usa `appsettings.Example.json` como plantilla.
- Mantén `appsettings.json`, `appsettings.Development.json` y secrets fuera del repositorio.
- Configura SMTP y PayPal con credenciales privadas en User Secrets.
- El usuario administrador inicial generado es `admin@airportwebapp.local` con contraseña `Admin123!`.
