# Setup

Sigue estos pasos para configurar y ejecutar AirportWebApp en desarrollo:

1. Clona el repositorio.
2. Asegúrate de tener .NET 10 SDK instalado.
3. Define las credenciales sensibles mediante User Secrets o variables de entorno.
4. Ejecuta `dotnet build` y `dotnet run`.

No registres credenciales reales en el repositorio.
